# MERN Stack Stock Trading Website - Zerodha Clone

A full-stack stock trading website built using the MERN (MongoDB, Express.js, React, Node.js) stack. This project replicates the core features of a stock trading platform, focusing on a seamless user experience for exploring and managing virtual stock trades.

## 🚀 Features

- **Dashboard**: View your portfolio, transaction history, and account summary.
- **Stock Search**: Look up stocks and view detailed information.
- **Responsive Design**: Optimized for desktop and mobile devices.

## 🛠️ Tech Stack

### Frontend:
- **React.js**: For building the user interface.
- **Redux**: State management for seamless data flow.
- **CSS/SCSS**: Styled components for a polished look and feel.

### Backend:
- **Node.js**: For handling server-side logic.
- **Express.js**: Lightweight framework for building the backend API.

### Database:
- **MongoDB**: NoSQL database for managing user data and stock information.

### Additional Tools:
- **Axios**: For API calls.
- **Mongoose**: For MongoDB object modeling.
